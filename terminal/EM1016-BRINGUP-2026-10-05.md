# EM1016 RS-232 Bring-Up — 2026-10-05

## Result

The Linux host and physical M6x09-I SBC have a verified, bidirectional serial connection.

The board emitted its `6809 MICROPROCESSOR KIT 2020` monitor banner after reset. The keypad **DUMP** function then produced a correctly formatted memory dump in the Linux Tcl/Tk terminal. This proves the complete serial path, including target transmit, host receive, and the monitor's terminal-output path.

Example received output began:

```text
0200:AA AA AA AA AA 8A AE AA EA BA BA AA AA 8A EA EA  ................
0210:AA AA AA AA AA AA AA AA EA 2A AA AA AA BA AA AB  .........*......
```

## Verified configuration

| Component | Verified configuration |
| --- | --- |
| Host adapter | Eminent/ACT EM1016, Prolific PL2303 (`/dev/ttyUSB0`) |
| Stable device name | `/dev/serial/by-id/usb-Prolific_Technology_Inc._USB-Serial_Controller_D-if00-port0` |
| Electrical path | SBC 6850 ACIA → HIN232/MAX232-class RS-232 transceiver → DB9 null-modem crossover → EM1016 → Linux |
| Serial settings | 19,200 baud, 8 data bits, no parity, 1 stop bit, no flow control |
| Monitor operation | Keypad-driven; **DUMP** sends terminal output and **LOAD** accepts Motorola S19 records |

## Cable requirement

The EM1016 and SBC are both DTE-wired. The required null-modem connection crosses DB9 pins 2 and 3, and keeps pin 5 straight through:

```text
2 ↔ 3
3 ↔ 2
5 ↔ 5
```

## Meaning

Linux is now a working development host for the M6x09-I. The next practical milestone is a controlled **LOAD** of a known-good S19 program into RAM, followed by keypad-based inspection and execution. ROM programming remains a later promotion step after RAM validation.
